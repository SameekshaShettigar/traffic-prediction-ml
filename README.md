🚦 Traffic Prediction System using Machine Learning

📌 Overview

This project is a supervised machine learning-based system that predicts traffic volume based on city and time.
It uses real-world Uber pickup data as a proxy to estimate traffic density and helps in understanding congestion patterns.


🎯 Objectives

Predict traffic volume using time and location
Analyze traffic patterns using real-world data
Build an interactive user interface for predictions


🧠 Technologies Used

Python
Pandas & NumPy – Data processing
Scikit-learn – Machine Learning (Random Forest)
Streamlit – Web UI
Matplotlib – Data visualization


📊 Dataset

Uber Pickups Dataset (NYC)
Source: Kaggle
Contains timestamp and location of Uber pickups


🧾 Use Cases

Smart traffic management
Urban planning
Congestion prediction
Smart city applications
