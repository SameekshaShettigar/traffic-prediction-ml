🚦 Traffic Prediction System using Machine Learning

📌 Overview
This project predicts traffic volume based on city and time using a Random Forest regression model.
It uses real-world Uber pickup data as a proxy for traffic density across New York City boroughs.



🎯 Features
📊 Predict traffic volume based on time and location
🌆 Multi-city support (New York, Manhattan, Brooklyn, Queens, Bronx)
⏰ AM/PM time selection via interactive UI
📈 Machine Learning model — Random Forest Regressor
💻 Interactive web interface using Streamlit
